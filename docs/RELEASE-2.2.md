# Trun Game Free Mega 2.2 — Native Red Edition

Nova logo do chapéu vermelho com faixa preta e catálogo com **40 links**: Nintendo, Sony, Microsoft, Sega, Capcom e Commodore.

## Novidades

- Busca, filtros por categoria e botões COPIAR e ABRIR.
- Histórico local DataSense e preferência de idioma.
- Interfaces Windows Forms, Tcl/Tk e SwiftUI.
- Instaladores e reparadores próprios de cada sistema.
- Atalho Windows na pasta do projeto; arquivos auxiliares ocultos.
- BUILD SUCCESS/FATAL ERROR com detalhes em Read More.
- Os 16 créditos originais preservados.

## Instalação

Baixe **Trun-Game-Free-Mega-2.2.zip** em Assets e extraia tudo. O RAR original também está disponível.

| Sistema | Instalar | Abrir após instalar |
| --- | --- | --- |
| Windows 10/11 | `Installer Windows.bat` | `Trun Game Free Mega.lnk`, na mesma pasta. |
| Linux com Tcl/Tk | `sh "Installer Linux.sh"` | `.desktop`, na pasta ou no menu de aplicativos. |
| macOS com ferramentas Swift | `Installer macOS.command` | `.app` compilado na pasta. |

No Windows, ative **Itens ocultos** para acessar novamente os instaladores e auxiliares. O atalho permanece visível. Use o arquivo Repair do seu sistema para reparar; DataSense é preservado.

O pacote não inclui ROMs nem um aplicativo macOS previamente compilado/notarizado. Os scripts e as imagens foram preservados como recebidos. Consulte o README e os documentos de revisão/validação para requisitos e limites dos testes.

**Integridade:** `SHA256SUMS.txt` identifica os dois pacotes. O ZIP reproduz os mesmos 27 arquivos do RAR original.
