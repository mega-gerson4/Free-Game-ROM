# Trun Game Free Mega 1.0

Catálogo para Windows com **19 entradas de links** organizadas entre Nintendo, Sony/PlayStation e Microsoft/Xbox, com interface, logo, créditos e instalador de atalhos.

## Como instalar

1. Baixe **Trun-Game-Free-Mega-1.0.zip** em **Assets**.
2. Extraia todos os arquivos para a pasta em que pretende manter o aplicativo.
3. Execute **Installer Links.bat** e aguarde a mensagem de conclusão.
4. Abra o atalho **Trun Game Free Mega** criado na área de trabalho.

Ao clicar em uma entrada, o catálogo **copia o endereço**. Cole-o no navegador para acessá-lo. O ZIP não inclui jogos ou ROMs.

O instalador oculta quatro arquivos de origem depois de gerar os atalhos. Se mover a pasta, abra o atalho e use **Reparar problema** para selecionar o local atual.

O atalho pronto do pacote original foi retirado desta distribuição porque usava caminhos do computador de origem. Os 11 arquivos restantes do aplicativo foram preservados, e o instalador gera o atalho de cada computador.

O código tem como alvo Windows 10/11 e depende de Windows PowerShell, Windows Forms e Windows Script Host/VBScript. Não há validação de todos os modelos de CPU ou GPU nem tempos garantidos. A instalação dos atalhos ocorre localmente, sem download pelo script.

Avisos de fornecedor desconhecido ou do SmartScreen podem aparecer. Confira a origem e os scripts antes de decidir executar; a revisão estática não certifica segurança. Veja o README e `docs/REVISAO.md` no repositório.
