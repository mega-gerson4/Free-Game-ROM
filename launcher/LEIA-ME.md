# Iniciar o catálogo

Mantenha todos os arquivos desta pasta juntos. No Windows, execute `Installer Links.bat`, aguarde a conclusão e abra o atalho criado na área de trabalho.

O instalador oculta quatro arquivos depois de criar os atalhos. Para vê-los, ative **Itens ocultos** no Explorador. Se mover a pasta, use **Reparar problema** no atalho.

Clicar em uma entrada copia o endereço. Cole no navegador para acessá-lo. Os jogos e ROMs não estão incluídos.

Leia o [README principal](../README.md) para instalação, compatibilidade, créditos e avisos do Windows. Suporte: mega.gerson44888@gmail.com.
